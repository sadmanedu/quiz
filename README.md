# ঝিলমিল কুইজ

বাংলাদেশের দ্বিতীয় শ্রেণির শিশুদের জন্য একটি রঙিন, শিশুবান্ধব কুইজ ওয়েবসাইট।

## আছে যা যা

- হোম পেজে বাংলা, English, গণিত ও সাধারণ জ্ঞানের বিষয়ভিত্তিক গ্রিড
- বাংলা বিষয়ের জন্য **সম্পূর্ণ বই** ও **অধ্যায়ভিত্তিক**—দুটি আলাদা পথ
- বাংলা বইয়ের ৫৩টি পাঠের তালিকা; প্রতিটি পাঠে ২০টি প্রশ্ন ও বাংলা ব্যাখ্যা
- সম্পূর্ণ বই থেকে প্রতিবার নতুন ১০ প্রশ্নের র‌্যান্ডম অনুশীলন
- অন্য বিষয়গুলোর জন্য ৩টি করে ছোট কুইজ
- তাৎক্ষণিক উত্তর-ফিডব্যাক, বাংলা ব্যাখ্যা ও ফলাফলের পাতা
- তারা সংগ্রহ ও সম্পন্ন কুইজের অগ্রগতি ব্রাউজারে সংরক্ষণ
- মোবাইল ও ডেস্কটপ—দুই ধরনের স্ক্রিনের জন্য উপযোগী ডিজাইন

## চালানো

কোনো build step দরকার নেই। রিপোজিটরির মূল ফোল্ডার থেকে চালান:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

তারপর ব্রাউজারে `http://localhost:4173` খুলুন।
